Contexto e Importância

Sistemas Ciberfísicos Críticos

Formam a base de infraestruturas essenciais:

  • Redes elétricas inteligentes (Smart Grids)
  • Sistemas de abastecimento de água
  • Ambientes industriais (manufatura, processo)
  • Sistemas de transportes e saúde

Ataques Históricos Críticos

  • Stuxnet (2010): Danificou instalações nucleares iranianas
  • BlackEnergy (2015): Causou apagões em cascata na Ucrânia
  • Ekans & LockerGoga: Ransomwares desenhados para sistemas industriais
⚠️ Realidade Crítica: 65% das organizações possuem acesso remoto inadequadamente seguro a sistemas CPS

O Problema: Quatro Desafios Principais

1. Escassez de IDS Eficazes para CPS

Sistemas existentes foram desenvolvidos para ambientes corporativos. Protocolos heterogéneos industriais (Modbus, S7Comm, DNP3) carecem de soluções específicas.

2. Detecção de Ataques Orquestrados Multi-Fase

Ameaças Persistentes Avançadas (APTs) executam múltiplas fases coordenadas: reconhecimento → compromisso → movimento lateral → persistência. IDS tradicionais analisam eventos isolados.

3. Limitações de Datasets Existentes

Datasets públicos (UNSW-NB15, CICIDS2017, X-IIoTID) sofrem de desequilíbrio severo, falta de ataques multi-fase realistas e ausência de contexto operacional.

4. Gerar Dados Realistas

Simular infraestruturas industriais complexas com múltiplos protocolos e campanhas de ataque multi-fase é extremamente desafiador.

A Solução: Arquitectura Integrada

Componente 1

Dataset Robusto
  • Ambiente reconfigurável baseado em Docker
  • Protocolos industriais (Modbus/TCP, MQTT)
  • Campanhas multi-fase controladas
  • Labeling preciso (Ground-Truth)

Componente 2

Classificação ML
  • Random Forest, XGBoost, AdaBoost
  • Features multi-nível (rede, host, app)
  • Precisão >90% (objetivo)
  • Escalável para novos ataques

Componente 3: Correlação & Rastreamento

  • Clustering de eventos (K-Means, DBSCAN) para agrupar ações relacionadas
  • Análise temporal para reconstruir kill chains
  • Detecção precoce de APTs antes de danos operacionais

Arquitetura Modular do IDS

Módulo 1: Classificação de Ações

Entrada: Fluxos de rede etiquetados

Processamento: Modelos ML (Random Forest, XGBoost) classificam cada evento

Saída: Eventos classificados como normais ou categorias de ataque

⬇ Correlação Temporal ⬇

Módulo 2: Correlação & Predição de Campanhas

Entrada: Ações de ataque classificadas

  • Correlação espacial e temporal de eventos
  • Identificação de sequências (kill chains)
  • Atribuição a campanhas específicas

Vantagem: Cada módulo pode ser otimizado independentemente. Classificadores precisos não dependem de correlação.

Desafios Antecipados

1. Desequilíbrio de Classes

Ataques são eventos raros. Mitigação: SMOTE, weighted loss functions, balanceamento parametrizado no gerador de dados.

2. Generalização de Modelos

Modelos treinados em simulação podem não generalizar. Foco em features semânticas (nível de protocolo), não apenas estatísticas agregadas.

3. Correlação Multi-Atacante

Distinguir entre múltiplos atacantes simultâneos é complexo. Uso de técnicas probabilísticas e análise de contexto operacional.

4. Requisitos de Tempo Real

IDS deve processar com latência <100ms. Otimização agressiva do pipeline e dos modelos necessária.

Estratégia: Endereçar cada desafio iterativamente durante fase de desenvolvimento
